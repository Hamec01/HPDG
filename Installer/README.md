# Бета HPDG

Windows 10/11 x64, версия **0.1.0 Beta 3**, только VST3, без активации.

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File Installer\Build-Beta.ps1
```

Нужны CMake и Visual Studio с инструментами C++. Скрипт собирает только
HPDG_VST3, получает официальный подписанный Visual C++ Runtime и при
необходимости распаковывает подписанный Inno Setup 6.7.3 в build/tools.
Можно указать собственный компилятор через -CompilerPath.
Для уже собранного актуального пакета: -SkipBuild.

Результат: Releases/HPDG_VST3_Setup_0.1.0-beta.3.exe, SHA-256 установщика,
манифест всех файлов библиотеки, FAQ и уведомление о правах. Перед упаковкой
скрипт проверяет каждый файл библиотеки в VST3 по SHA-256 и отсутствие
устаревших файлов. Все 913 аудиофайлов и JSON с исходными именами обязательны.

Установка требует администратора и использует стандартную папку
C:\Program Files\Common Files\VST3\HPDG.vst3. Библиотека находится в
Contents/x86_64-win/Samples, документация — в Documentation.
Установщик включает x64 Runtime и запускает его только при отсутствии
достаточно новой версии. FAQ и удаление доступны через Пуск → HamloProd.
Не меняйте идентификаторы VST3: они сохраняют совместимость с проектами.

Для изолированной проверки упаковки используйте -TestInstaller -SkipBuild.
Тестовый EXE пишется только в build/installer-test-output, не регистрирует
приложение и ярлыки и не обновляет системный Runtime. Запускайте его с
/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="абсолютная тестовая папка"
/LOG="абсолютный путь журнала". Затем сверяйте библиотеку с манифестом
и запускайте созданный в тестовой папке unins000.exe для проверки удаления.
Готовая автоматическая проверка: Installer/Test-BetaInstall.ps1. Она проверяет
установку, очистку устаревших фабричных файлов при обновлении, SHA-256 каждого
файла библиотеки, документацию, загрузку установленной VST3 DLL и удаление.

Samples и установщик первой беты с его SHA-256 включаются в Git; остальные
файлы Releases и build игнорируются. Для пользовательского
пуша добавьте также удаления старых имён семплов и новые sample-names.json.
Готовый установщик также можно распространять как отдельный артефакт релиза.

## Выпуск обновления

1. Номер версии записан только в `CMakeLists.txt`: `project(HPDG VERSION x.y.z)` и
   `set(HPDG_VERSION_LABEL "beta.N")` (для финального релиза метка пустая). Шапка
   плагина, установщик и имена файлов в Releases берут версию оттуда
   (через `Installer/HpdgVersion.ps1`).
2. Соберите установщик через `Build-Beta.ps1` и проверьте его через `Test-BetaInstall.ps1`.
3. Посчитайте SHA-256 установщика:
   `(Get-FileHash Releases\HPDG_VST3_Setup_<версия>.exe -Algorithm SHA256).Hash.ToLower()`.
4. Загрузите установщик в приватное хранилище сайта (Contabo S3,
   `hamloprod-private/hpdg/`) вместо старого и обновите
   на сайте запись о релизе: версия (`0.1.0-beta.4`), название, описание, путь к файлу,
   SHA-256, размер (подробно — `docs/SITE_UPDATES_TASK.md`). Плагин читает её через
   `GET https://hamloprod.org/api/hpdg/latest`: в шапке кнопка **Update** покажет
   `Update: <версия>`, а покупатель с ключом скачает установщик прямо из плагина
   (`POST /api/hpdg/download`, проверка SHA-256, запуск после подтверждения).
5. Разошлите покупателям письмо о новой версии (рассылка сайта по базе ключей). Публичного
   GitHub-репозитория для релизов нет: установщик уходит только покупателям.
