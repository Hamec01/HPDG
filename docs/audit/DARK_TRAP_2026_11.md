# DarkTrap — разбор новых референсов, 2026-11-01

Задача: приблизить весь подстиль к указанным Metro Boomin / 21 Savage референсам,
особенно взаимодействие 808, кика и хэтов. SynthBassVST делает другой агент:
параметры и требования к исполнению вынесены в `docs/SYNTHBASSVST_DARKTRAP_HANDOFF.md`.
Сборка и установка VST оставлены владельцу; здесь собираются только проверочные executables.

## Источники и метод

Все 11 локальных MP3 прочитаны. У них разные SHA-256; два NOIR также различаются по
темпу и басовой линии. Для каждого исследованы два 24-секундных окна, начинающихся
на 28% и 60% длительности: всего 528 секунд. Валидационная подборка до настройки:
RASSVET, LEGEND, OUR LORD; остальные восемь — калибровочная.

- Demucs `htdemucs`, CPU, shifts=0, фиксированный seed; исходники и stems находятся
  только в игнорируемом `build/darktrap-reference/`.
- Существующий `HPDG_BreakLab`: темп, K/S/H и тональные сегменты баса. Окна сохраняются
  раздельно: переход между несоседними фрагментами не считается музыкальным интервалом.
- Хэты: high-pass 7 kHz, onset envelope с шагом 128 samples при 44.1 kHz;
  интервалы считаются в физическом времени на предполагаемом Trap-темпе.
  Roll требует трёх последовательных коротких интервалов. Быстрая основа сама по себе
  не считается роллом.
- Тембр: YIN + спектральный пик около оценённого основного тона, устойчивые участки нот.
  Отдельно сверены огибающие исходного микса и bass stem у NOIR, OMEN, TRUST и Nothing Personal.

Это автоматические оценки по сведённым записям, не ручная MIDI-разметка. Оценки высоты
могут объединять повторы одного тона и разделять один бас на сегменты. MIDI gate,
естественный decay и слышимый хвост по этим данным не тождественны.
Гармоники stems содержат обработку микса и ошибки разделения.

Важные отклонённые измерения:

- Возврат уровня bass stem после кика давал ложный 808 onset. В исходном миксе в этот
  момент виден **положительный пик кика**, а в stem — провал. Счётчик таких «атак»
  оставлен диагностическим и не использован для настройки плотности 808.
- Сильнейший FFT-пик иногда оказался второй гармоникой: например, оценка Nothing Personal
  около 87 Hz после проверки стала около 44 Hz.
- Pitch-punch по первым zero crossings давал ложные 18–19 semitones. Такие числа
  не переданы как настройки синтезатора.

## Принятые изменения

- **Контраст длительностей.** В разреженном Dark (Density < .35) один из четырёх вариантов
  по seed использует более редкие опорные 808, которые могут держаться через снейр и
  тактовую черту. У обычных вариантов остаются независимые ответы баса. Максимум gate
  — восемь четвертей, дальше возможна пауза; всё ограничено концом паттерна.
- **Короткая артикуляция.** Pickup перед опорной нотой сохраняет короткий gate и повторяет
  её высоту. При возможности второй удар пары уже подкреплён киком; новые случайные кики
  ради этой пары не добавляются.
- **Точность MIDI.** Для Dark 808 сохранены длительности PPQ вместо округления вверх до 1/16.
  После валидации gate ограничен следующим началом; старый Note Off не пересекает новую
  басовую атаку. Locked lanes защищены существующими границами редактирования.
- **Хэты.** Восьмая основа сохранена. Редкий Style roll стал полноценной короткой дробью,
  обычно триольной, в зоне акцента кика/баса. Он заменяет свой отрезок carrier.
  Fills продолжает запрашивать дроби на окончаниях; Off убирает roll events.
  Gate roll-нот сохраняет короткое разрешение, без перекрывающихся длинных 1/16.
- **Снейры и кик.** Сохранены отдельный опорный снейр, дополнительные мягкие снейры,
  редкие articulation kicks и независимость части ударов кика от начал баса.
  Их коэффициенты не перенастраивались по сомнительным onsets.
- **Оценщик.** Для Dark с удерживаемой нотой длиной от такта учитывается звучащий бас под
  киком. Чистый onset coupling остаётся отдельной неизменённой метрикой. Пустой промежуток
  не получает sustain credit. У остальных подстилей прежняя логика оценки.
  Исправлен и расчёт покрытия: старый lookback матрицы ограничивался одним тактом.
  Для Dark включён учёт двухтактовых 808; прежний путь остальных подстилей сохранён.

Число кандидатов не увеличено. Анализ MP3/видео не входит в плагин или audio callback.
Голоса/сэмплы 808 в этой задаче не пересинтезировались: для SynthBassVST передан отдельный
контракт gate, sustain, release, высоты, мягкого насыщения и фильтра.

## Воспроизведение исследования

```
python tools/darktrap_reference_audit.py inventory
python tools/darktrap_reference_audit.py fetch

python tools/darktrap_reference_audit.py transcripts

python tools/darktrap_reference_audit.py timbre-yin

python tools/darktrap_reference_report.py corpus
```

Для загрузки видео требуется локально доступный yt-dlp; для анализа — numpy, scipy,
soundfile, librosa, Demucs/PyTorch, ffmpeg, matplotlib. ASR нужна только для отсутствующих
субтитров. Это инструменты разработки, не зависимости HPDG.

Проверочный стенд фиксирует BPM (`--bpm 150` включает BPM Lock), seed 1–1000,
4 такта, Style rolls, Density .20/.40/.80. При `--notes` пишет также хэты, роль и Density,
что позволяет проверять настоящие roll/gate интервалы после всего processor pipeline.
До изменения сохранён отдельный executable; исходные и итоговые прогоны используют
одинаковые настройки и исходный набор сидов.

## Итоговая проверка

Основное сравнение: по 1000 seeds для Density .20/.40/.80 при 150 BPM, четыре такта,
Style rolls. Ниже — средние по одинаковым наборам, после полного processor pipeline.

| Density | 808/такт до → после | Средний gate 808, четверти до → после | Kick/такт до → после | Паттерны с полноценной дробью до → после |
|---|---:|---:|---:|---:|
| .20 | 2.36 → 1.92 | 1.54 → 2.86 | 1.87 → 1.88 | 4.0% → 8.2% |
| .40 | 2.42 → 2.40 | 1.49 → 1.66 | 1.91 → 1.92 | 4.1% → 10.2% |
| .80 | 2.55 → 2.52 | 1.40 → 1.56 | 1.96 → 1.96 | 2.7% → 7.0% |

В обычной .40 хэты остались около 8 нот/такт (8.04 → 8.03), eighth coverage
94.86% → 94.63%, дополнительные снейры .307 → .300/такт. Плотность не поднималась
ради самой плотности. Рост счётчика `bassShortRate` связан также с устранением
округления длительностей около порога 1/8; он не означает троекратного роста атак.

На этих 3000 паттернах до/после: structural failures 0, determinism failures 0,
exact duplicates 0. Near duplicates .20: .5% → .2%; .40: .2% → .1%; .80: .8% → .8%.
Отдельные 1000 Dark/Fills: 1000/1000 паттернов с полноценной дробью, failures 0,
determinism failures 0. Off проверен существующим тестом на 64 seeds.

Остальные пять Trap-подстилей: 5000 одинаковых seed/config controls; все семь
контрольных hashes совпали в каждом паттерне. Основные engine-тесты: 90/90;
проверки processor/lane границ, sample guidance, export и Sync: 38/38.
В полном note dump проверены 2350 коротких пар: 0 разрывов связи высоты pickup
с последующей нотой, 0 перекрывающихся басовых MIDI gates.

Последовательный замер скорости, отдельно от параллельной сборки и прочих аудитов:
по 1000 seeds, 150 BPM, Density .40, без notes/WAV export. p50 **20.29 → 22.05 ms**,
p95 **27.27 → 28.97 ms**, worst **38.36 → 33.17 ms**. Медиана выросла примерно на
1.8 ms; это стоимость генерации/оценки кандидатов, не работа в audio callback.
Машина остаётся общей, поэтому небольшие отличия timing не следует считать строгим
результатом выделенного performance-стенда.

Малые сохраняемые артефакты: `quality-lab/darktrap-2026-11/checks.json`,
`comparison.json`, `performance.json`, `before_summary.json`, `after_summary.json`,
`fills_summary.json`. В `checks.json` также SHA-256 executables до/после.
Их пересчёт: `python tools/darktrap_reference_report.py proofs`.

Валидационные MP3 не дают единственной «правильной» средней длины: их track-mean
1.18, 1.53 и 2.35 четверти. Обычный Dark после правок — 1.66, а длинная разреженная
семья доступна при .20. Это подтверждает покрытие разных случаев, но не является
оценкой слуховой похожести в процентах. Более активный и разреженный варианты остаются
предметом ручного прослушивания.

Неподобранные по score примеры seeds 1–3:
`quality-lab/darktrap-2026-11/listening/{before,after,fills,sparse}`.
Там WAV полного рисунка / кика / баса и MIDI с длительностями. Примеры использовали
штатный renderer HPDG; отдельный SynthBassVST не подключался. Все сторонние аудио/видео
сохранены только в игнорируемом исследовательском кеше.

Последующее уточнение — генерация под музыкальный сэмпл с информацией анализатора,
без оценки копирования драмов: `docs/audit/DARK_TRAP_SAMPLE_GUIDANCE.md`.
