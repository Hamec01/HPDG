HPDG 0.1.0 Beta 2 — HamloProd
Windows 10/11, x64, только VST3.

Включены VST3, полная библиотека из 849 аудиосемплов, руководство
и уведомления о правах. Ключ активации и подключение к интернету для
работы плагина не требуются. Microsoft Visual C++ Runtime включён
в установщик и устанавливается при необходимости.

Закройте DAW перед установкой. Плагин устанавливается в стандартную
папку Windows: C:\Program Files\Common Files\VST3\HPDG.vst3.
Семплы находятся внутри этого пакета рядом с бинарным файлом плагина.
После установки выполните повторное сканирование VST3 в своей DAW.

Это бета-версия: сохраняйте рабочие проекты и сообщайте об ошибках
с указанием DAW, версии Windows, жанра и последовательности действий.
Standalone в данный выпуск не входит.

Что нового в Beta 2:
- Trim sample: кнопки Loop / Play / Stop; при перетаскивании границ звук
  больше не перезапускается; клик по волне ставит курсор воспроизведения.
- Trim sample: поле «Selection = N bars» — выбираете, сколько тактов
  в выделении, и темп считается из него (например, ровно 4 такта).
- Sub808 играет ноты так, как они написаны; кнопки − / + на дорожке баса
  меняют октаву (Shift — полутон), это сохраняется в MIDI-экспорте.
- Скины Dark и Steel, переключение прямо из меню SKIN.
- Techno: второй набор ударных (тек-хаус) и басы, 100 новых семплов.
