# Techno: анализ структуры и формулы генерации

Документ описывает модель, по которой движок HPDG генерирует техно-барабаны и бас.
Движок изолирован: он живёт в `Source/Engine/Techno/` и `Source/Engine/TechnoEngine.*`
и не меняет генерацию других жанров.

## 1. Что такое техно-грув (выводы из литературы)

| Наблюдение | Источник |
|---|---|
| Техно относится к «four-on-the-floor» жанрам: бочка на каждой доле — неизменная ось, вокруг которой строится всё остальное. Синкопа и «метрический диссонанс» создаются слоями поверх этой оси, а не смещением бочки. | Butler, *Unlocking the Groove* (2006) |
| Базовая ячейка танцевальной музыки — пара «бочка на долю / хэт на офбит» («poum-tchak»): тело «падает» на долю и «поднимается» на офбите. | Zeiner-Henriksen, *The PoumTchak Pattern* (2010) |
| Перкуссия в EDM часто строится по группировке 3+3+2 и родственным «евклидовым» ритмам (максимально равномерное распределение k ударов по n шагам). Повторение 3-шаговой ячейки поверх 4/4 — это группирующий диссонанс (полиметр). | Butler (2006); Toussaint, *The Euclidean Algorithm Generates Traditional Musical Rhythms* (2005) |
| Зависимость «желания двигаться» от синкопы имеет форму перевёрнутой U: максимум при средней синкопе. | Witek et al., PLoS ONE 9(4):e94446 (2014) |
| Синкопа меряется метрическими весами: нота на слабой позиции, за которой следует пауза на более сильной, даёт вклад, равный разнице весов. | Longuet-Higgins & Lee (1984); полифоническая версия у Witek et al. (2014) |
| Техно — музыка повторения и постепенного изменения: материал меняется малыми мутациями на границах 4/8/16 тактов, а не новыми риффами в каждом такте. | Butler (2006), анализ формы трека |

Особенности баса в техно (практика жанра, сверено с типовыми продакшн-приёмами):
1. Бас не бьёт вместе с бочкой (сайдчейн): атаки баса стоят между долями.
2. Высот очень мало: тоника занимает 55–80% нот. Дальше идут октава, квинта, b7, b3, в «тёмных» стилях b2 (фригийский лад). Гармония меняется редко: раз в 4–8 тактов или никогда.
3. Ритмические архетипы: офбит-бас, «катящийся» 16-й бас (галоп), рамбл (низкочастотный хвост бочки на 16-х после доли), acid-линия 303 (16-е с акцентами, глайдами и октавными скачками), минимальный пульс, даб-стаб.

## 2. Сетка и метрические веса

Такт делится на 16 шагов `s = 0..15` (шестнадцатые, 240 PPQ). Роллы хэтов используют 32-е.

Метрический вес (иерархия Лердала–Джекендоффа, как у Longuet-Higgins & Lee):

```
w(s) = 1.00  если s = 0          (сильная доля такта)
       0.75  если s = 8          (третья доля)
       0.60  если s mod 4 = 0    (доли 2 и 4)
       0.35  если s mod 2 = 0    (офбит-восьмые 2, 6, 10, 14)
       0.15  иначе               (16-е)
```

## 3. Барабаны

### 3.1 Бочка — ось

```
K(b) = {0, 4, 8, 12}                                   — в каждом такте b
+ подхват: s ∈ {14, 15} с вероятностью p_pick, только в «ответных» тактах (b mod 2 = 1)
− дроп: s = 12 последнего такта фразы убирается с вероятностью p_drop (брейк перед «единицей»)
```

Жёсткий гейт: целостность оси `A = (доли с бочкой) / (все доли без такта-сбивки) ≥ 0.95`.

### 3.2 Рамбл (полоса Kick Ghost)

Хвост бочки на 16-х после доли, `d` — расстояние от доли в шагах:

```
onset(s) при d = s − 4·floor(s/4) ∈ {1, 2, 3},   P(onset) = p_rumble
v(d) = v₀ · γ^(d−1),   γ = 0.72
```

### 3.3 Клэп / снейр

```
C = {4, 12} с вероятностью p_clap (по стилю)
в ответных тактах: смещённый клэп на s = 13 или 15 с вероятностью p_disp
```

Гейт: клэп никогда не стоит на шагах 0 и 8.

### 3.4 Хэты

Офбит-оупен (полоса OpenHat), это «tchak»: `O = {2, 6, 10, 14}` с вероятностью p_offOpen.

Закрытый хэт (полоса HiHat): режим несущей выбирается по стилю и плотности:
восьмые / шестнадцатые / «16-е без долей» (s mod 4 ≠ 0) / офбит.
Громкость задаётся акцентным профилем внутри доли:

```
A = [0.55, 0.35, 1.00, 0.42]   (позиция s mod 4: доля, e, and, a)
v(s) = v_min + (v_max − v_min) · A[s mod 4] · (1 + h·u),   u ~ U(−1, 1), h — humanize
```

Если на шаге звучит оупен-хэт, закрытый на этом шаге глушится (choke).

Райд (полоса Ride): восьмые с акцентом на офбитах, `v_off = 1.0`, `v_on = 0.6`.

### 3.5 Перкуссия: евклидовы и полиметрические циклы

Евклидов ритм E(k, n) с поворотом r (алгоритм Бьорклунда):

```
hit(i) ⇔ floor((i + r) · k / n) ≠ floor((i + r − 1) · k / n),   i = 0..n−1
```

Кандидаты: `E(3,8)` (3+3+2, тресилло), `E(5,16)`, `E(7,16)`, `E(5,8)`, а также полиметр
длиной `L ∈ {3, 5, 6, 7}` шагов, перезапускаемый каждый такт: `hit(s) ⇔ s mod L ∈ P`.

Маскировка: удар перкуссии, совпавший с бочкой, сдвигается на +1 шаг или удаляется.

### 3.6 Хэт-FX и тарелка

- Ролл в конце 4-го и 8-го такта: 32-е на s = 14–15 с крещендо, `v_i = v₀ + Δ·i`.
- Креш: на s = 0 первого такта фразы (и на такте 8 в 16-тактовой фразе) с вероятностью p_crash.

### 3.7 Фраза

Роли тактов для фразы из P тактов:

```
role(b) = F  (сбивка)  если b = P − 1 и P ≥ 4 (с вероятностью p_fill)
          A' (вариант) если b mod 4 = 3 или b mod 2 = 1 (ответ)
          A            иначе
```

Вариант A' — это малая мутация A: поворот перкуссии на 1–2 шага, подхват бочки, смещённый клэп, лишний хэт.
Сбивка F: дроп бочки на последней доле, ролл хэтов, клэп-флэм.

## 4. Оценка кандидата (поиск в зоне качества)

Генерируются N = 48 кандидатов. Каждый оценивается, а выбор делается softmax-ом
среди почти лучших, поэтому случайность выбирает только между хорошими вариантами.

**Синкопа** (полифоническая, Witek 2014). Для каждого слоя ℓ с весом λ_ℓ
(бочка 2.0, клэп 1.5, перкуссия 1.2, хэт 0.6):

```
S = (1 / bars) · Σ_ℓ λ_ℓ · Σ_{onset n, пауза в r} max(0, w(r) − w(n)),
r — следующая позиция сильнее n внутри доли
```

**Посадка на цель** (перевёрнутая U):

```
G(x; x*, σ) = exp(−(x − x*)² / (2σ²))
```

**Компоненты:**
- `f₁` — целостность оси A (бочка на долях);
- `f₂ = 1 − M` — взаимосвязь слоёв, где M — доля ударов перкуссии и хэтов, маскирующих бочку;
- `f₃ = G(S; S*, 0.35·S*)` — синкопа у цели стиля;
- `f₄ = G(D; D*, 0.25·D*)` — плотность у цели стиля: взвешенные удары на 16-ю без бочки (хэт, оупен, райд, рамбл 0.5; клэп, перк 1.0; ролл 0.25);
- `f₅ = G(R; R*, 0.05)` — повторяемость: R — средний Жаккар соседних тактов;
- `f₆` — разрешение фразы: сбивка только в конце, после неё снова «единица».

```
Q = (f₁² · f₂ · f₃ · f₄ · f₅ · f₆)^(1/7) − штрафы
```

Гейты (отбраковка без шансов): A ≥ 0.95, клэп не на 0/8. Перкуссия не ставится на бочку (ни на оси, ни на подхвате), закрытый хэт не звучит под оупеном, ось бочки не сдвигается дальше ±2 PPQ: это гарантирует конструкция, и тесты проверяют это.

## 5. Бас

### 5.1 Сайдчейн-модель

Пусть `d(s)` — число шагов от последней бочки. Атака баса разрешена только при d ≥ 1.
Её «вес» повторяет огибающую сайдчейна:

```
g(d) = 1 − exp(−d / τ),   τ = 1.1 шага
```

Громкость ноты `v = v₀ · (0.55 + 0.45 · g(d))`. Поэтому офбит (d = 2) звучит громче всех.

### 5.2 Ритмические архетипы

| Архетип | Атаки (d от доли) | Длина | Стиль |
|---|---|---|---|
| Offbeat | d = 2 | ½–¾ восьмой | Peak Time, Detroit |
| Rolling (галоп) | d ∈ {1, 2, 3}, `v = v₀·0.85^(d−1)` | 16-я | Peak Time, Hard |
| Rumble | d ∈ {1, 2, 3}, тихо, легато, только тоника | легато | Hypnotic, Hard |
| Acid 303 | каждый шаг с `p_on`, акцент `p_acc`, глайд `p_slide`, октава `p_oct` | 16-я / легато при глайде | Acid |
| Pulse | d = 2 через долю, длинные ноты | ½–1 доля | Minimal |
| Dub | d = 2 и d = 3+4, длинные ноты, квинты | до следующей атаки | Dub |

Кнопки баса: [1] прореживает атаки до половины, [2] — плотность стиля, [3] — плотнее
(Offbeat → Rolling, Acid `p_on + 0.15`).

### 5.6 Оценка баса

Кандидаты баса (N = 32, архетип тянется из весов стиля) оцениваются так:

```
гейт:   ни одной атаки на шаге бочки
root  = доля нот на корне такта,        f_root = G(root; π_I + π_VIII (+0.25 для Rumble), 0.18)
dens  = нот на такт,                    f_dens = G(dens; T_a · k_amount, 0.35·T)   T = [4, 10, 10, 9, 2, 3], k = [0.55, 1, 1.35]
rep   = Жаккар атак соседних тактов,    f_rep  = G(rep; 0.82 (Acid 0.60), 0.18)
f_smp = 0.6, если у сэмпла сильный бас, а архетип плотный (Rolling / Acid), иначе 1
Q     = (f_root · f_dens · f_rep · f_smp)^(1/4) · (0.6 + 0.4 · w_a / w_max)
```

Последний множитель — априор стиля: хорошо «севший» редкий архетип не должен вытеснять родной бас стиля.

### 5.3 Высота: марковская цепь со стационарным распределением стиля

Ступени `D = {I, VIII, V, b7, b3, IV, b2}`. Цепь возвращается к тонике:

```
P(j | i) = ρ · δ(j, i) + (1 − ρ) · π_j
```

Здесь ρ — инерция повторения (0.35–0.6), π — распределение стиля. Для Peak Time это
`π = [0.62, 0.14, 0.10, 0.06, 0.05, 0.03, 0]`, для Acid
`π = [0.42, 0.20, 0.10, 0.10, 0.10, 0.03, 0.05]`.
Первая нота каждой доли-группы — тоника с вероятностью π_I + 0.15.

Гармония: корень на 4 такта из набора прогрессий
`{i (статично) 0.6, i–VI 0.12, i–VII 0.12, i–iv 0.10, i–v 0.06}`.

### 5.4 Мотив и мутация

Бас — это 1-тактовый мотив M (Acid — 2-тактовый), повторяемый по фразе.
В тактах A' меняются 1–2 шага (сдвиг, пропуск, октава), в такте F последняя доля уходит в подход к тонике.

### 5.5 Сэмпл

С загруженным сэмплом (режим Guide) корень каждого такта берётся из баса сэмпла:
нота баса-линии, которая звучит дольше всех в такте. Если у сэмпла сильный собственный бас
(линия звучит больше половины времени), выбираются разреженные архетипы (Offbeat, Pulse, Rumble),
чтобы не спорить с ним. Бочка не подстраивается под пики сэмпла: ось four-on-the-floor неизменна.
