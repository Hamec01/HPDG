# DarkTrap 808 — контракт для SynthBassVST

Рабочий паспорт, 2026-11-01. Запрос владельца: отдельный агент делает SynthBassVST (808);
здесь исследуется и дорабатывается генерация всего DarkTrap. Этот документ разделяет
требования к исполнению MIDI, наблюдения по референсам и предлагаемые параметры синтеза.
Финальные замеры текущих 11 MP3 и сравнение генератора будут в
`docs/audit/DARK_TRAP_2026_11.md`. Чужое аудио не добавляется в репозиторий.

## Что требуется от синтезатора независимо от тембра

- Длина MIDI-ноты задаёт **gate**, а не скорость проигрывания готового one-shot.
  Длинная нота должна держать низ; короткая — действительно обрываться с коротким release.
  Gate в секундах = длина в четвертях × 60 / эффективный BPM.
- Не путать gate, естественный спад звучания и release после Note Off. Это три отдельных
  величины. Одинаковая волна должна исполнять и короткий повтор, и длинную опорную ноту.
- Mono, приоритет последней ноты, без суммирования нескольких сабов. Следующий обычный
  Note On переартикулирует звук; перекрытие для legato/glide не должно добавлять второй голос.
- Note Off старой ноты не должен выключать новую ноту. All Notes Off / reset транспорта
  обязаны гасить голос. Сглаживание gate/фазы защищает от щелчков на быстрых повторах.
- Хранить высоту как MIDI number и Hz: `f = 440 * 2 ** ((midi - 69) / 12)`.
  Подписи октав FL Studio отличаются от scientific pitch notation; на них контракт не строить.
- Отдельно `pitch_attack_semitones` + `pitch_attack_ms` (короткий спад атаки) и
  `glide_ms` (переход между нотами). Это разные движения высоты.
- Sync меняет перевод музыкальных длительностей во время, но не транспонирует осциллятор.
  Auto 70→140 уже разрешается в HPDG. Второй раз удваивать темп в синтезаторе нельзя.

## Предлагаемые управляемые параметры

Это интерфейс и начальные границы для настройки, **не извлечённые положения ручек авторов**.
По сведённому MP3 нельзя однозначно восстановить осциллятор, drive или ADSR исходного проекта.

| Параметр | Единица / смысл |
|---|---|
| `osc_shape` | sine body; регулируемая примесь мягко насыщенного тела, без обязательной яркой пилы |
| `sub_gain_db`, `body_gain_db` | основной тон отдельно от добавленных гармоник; сравнивать при равной громкости |
| `attack_ms` | подавление щелчка при Note On, не длинный fade-in |
| `hold_mode` | gate-follow; длинный sustain не должен автоматически превращаться в короткий pluck |
| `decay_ms`, `sustain_db` | естественный спад до уровня, который держится до Note Off |
| `release_ms` | спад **после** Note Off; учитывать длительность паузы перед следующей нотой |
| `pitch_attack_semitones`, `pitch_attack_ms` | короткий punch без длительного расстроенного баса |
| `glide_ms`, `glide_mode` | off / legato; выраженная длительность, без случайного glide на каждом повторе |
| `drive_db`, `drive_mix` | мягкое насыщение; нормализовать выход при сравнении |
| `lowpass_hz`, `lowpass_slope_db_oct` | отделить тёмное тело от высокочастотного треска |
| `highpass_hz` | опциональный инфранизкий фильтр; не срезать основной тон |
| `velocity_curve` | повторные ноты сохраняют вес; тихий pickup остаётся слышимым |
| `phase_retrigger` | явно заданная политика normal / legato с коротким сглаживанием |

## Какие измерения передавать, а какие не выдавать за точные

- По каждой записи: физический темп и выбранная half/double-time гипотеза;
  MIDI/Hz основного тона; число нот на такт; длительности в секундах и четвертях;
  повторные атаки одной высоты; доля совпадений с киком; паузы; темповые окончания фраз.
- Для тембра: h2/h1 и h3/h1 в dB на устойчивом участке; энергия полос относительно саба;
  скорость спада огибающей до следующей атаки; отдельно короткие и длинные ноты.
- Источник измерений — Demucs stems + проверка исходного микса. Separation может менять
  атаку, гармоники и хвост. Эти значения характеризуют оценку звучащего баса в миксе,
  а не чистый заводской патч или гарантированную MIDI-транскрипцию.
- Не подгонять волну по одному самому искажённому треку и не превращать весь DarkTrap
  в квадратную волну. Несколько семейств тембра допустимы при общей ритмической грамматике.

## Уже известные ограничения текущего HPDG

Предыдущий аудит `docs/audit/DARK_TRAP_PASSPORT.md` отмечал слишком короткие ноты:
1.38 четверти против 1.87 в прежней подборке. Это историческая оценка, её перепроверяем
на новом корпусе. Предыдущие исправленные голоса HPDG имели sine body + мягкое насыщение,
LPF 260–360 Hz для Dark, малую атаку высоты и длительное удержание. Сохраняем эти сведения
как исходную точку, не как итог нового анализа и не как обязательную реализацию SynthBassVST.

## Стартовый патч для разработки (предложение, не восстановленный пресет)

В процессе работы в общей папке появился `docs/audit/BASS808_CORPUS.md` второго агента:
672 отдельные 808 и уже настроенные Dark 1–3 в `Source/Audio/Synth808Voice.cpp`.
Для формы dry-волны и punch эти измерения предпочтительнее наших MP3 stems.
Старт для длинного саба — существующий **Dark 3**, обычного — Dark 1, округлого — Dark 2.
Наше дополнение — точное исполнение gate и возможность удерживать тело до Note Off.

| Контроль | Старт | Полезный диапазон для этого подстиля |
|---|---:|---:|
| Amp attack | 2 ms | 0.5–4 ms |
| Amp decay к удерживаемому уровню | 160 ms | 80–400 ms |
| Amp sustain | −1.5 dB от уровня тела | −4…0 dB |
| Release после Note Off | 30 ms | 12–60 ms |
| Pitch punch | существующие Dark 1–3: +16…20 semitones → 0 | для основной Dark-семьи примерно 14–22; чистый sub без punch — отдельный вариант |
| Pitch punch time constant | 26–40 ms в текущих Dark 1–3 | это tau экспоненты; не время полного успокоения высоты |
| Low-pass на F1 | около 300 Hz | 180–450 Hz без резонансного пика; учесть key tracking |
| High-pass | 20 Hz | 15–25 Hz, опционально; проверить ослабление самой низкой рабочей ноты |
| Glide | off по умолчанию | 20–90 ms только для явно заданного legato |
| Низ | mono | основной тон не расширять в стерео |

«Глубина» — вес основного тона и его удержание, а не обязательное опускание на октаву.
Главное тело — синус; дополнительное мягкое насыщение смешивается отдельно. Положения
drive ручек разных схем не сопоставимы: ориентироваться на результат при равной громкости.
В соответствии с dry-корпусом для основного тёмного патча ориентир — более слабая h2
(примерно −45…−20 dB, у округлого варианта ещё ниже) и h3 примерно −24…−12 dB.
Сделать также более насыщенный вариант; не навязывать его всем нотам и всем сидам.

Эти числа задают диапазон настройки и ещё требуют прослушивания. Быстрый спад уровня до нуля
за 100–300 ms превратит длинный саб в pluck независимо от правильного MIDI.

### Сопоставление с существующим Synth808Params

У Dark 3 сейчас: `punchSemitones=20`, `punchMs=26`, `drive=3`, `bias=.05`,
`saturation=.70`, `cutoffHz=450` **на C2**, `keyTrack=1`, `holdSeconds=1`,
`decaySeconds=.8`, `attackMs=3`, `clickDb=-48`, `boostDb=0`.
`decaySeconds` здесь задаёт время спада на 6 dB после timed hold, а не ADSR decay
до sustain. `punchMs` — tau; у измеренного Dark 3 punch около 11.5 st на 8–14 ms
и успокаивается примерно за 93 ms. Эти величины не взаимозаменяемы.

Параметры будущего gate-follow режима выше — отдельное предложение:
текущий `holdSeconds` в API не является таким режимом. Не переименовывать timed hold
в sustain без изменения поведения. Для длительных MIDI notes полезен явный выбор
timed one-shot / gate-follow с удерживаемым уровнем.

## Уроки проверки новых MP3

Машиночитаемый стартовый патч и единицы:
`docs/audit/reference/darktrap_synthbass_starting_patch.json`.
Измерения всех треков, включая waveform-related оценки:
`docs/audit/reference/darktrap_measurements_2026_11.json`.

Медианы основного тона по трекам после проверки YIN составили примерно 33–45 Hz.
Научные обозначения для сверки: MIDI 24 = 32.70 Hz, MIDI 28 = 41.20 Hz,
MIDI 29 = 43.65 Hz, MIDI 30 = 46.25 Hz, MIDI 36 = 65.41 Hz.
Это не ограничение всех нот диапазоном 33–45 Hz: речь о медианах разных записей.
Track-median h2/h1 разошёлся от −36 до +0.5 dB, h3/h1 — от −26 до −0.6 dB.
Такой разброс подтверждает несколько семейств звучания и влияние обработки; одного
«точного DarkTrap drive» по корпусу не существует.

Исследованы два 24-секундных фрагмента каждого из 11 файлов, с 28% и 60% длительности.
Провалы уровня в Demucs bass часто совпадают **с положительным пиком кика в исходном миксе**.
Возврат уровня после такого провала нельзя считать новым 808 Note On. Отдельный детектор
атак оставлен в локальном аудите как диагностический, его счётчики не являются MIDI-разметкой.
В TRUST и Nothing Personal видны протяжённые участки устойчивого низкого тона: gate-follow
с удерживаемым sustain здесь принципиален.

Не применять автоматически старую оценку pitch-punch по первым zero crossings: в этом
корпусе она возвращает и ложные скачки около 18–19 semitones. Сильнейший пик FFT иногда
попадает во вторую гармонику; для оценки основного тона добавлена проверка YIN.
Сведения о глубине/волне из stems остаются оценками звучания в миксе, не dry-патча.

## Приёмка исполнителя баса

Проверить одинаковую ноту на gate 1/16, 1/8, 1/4, 1, 2 и 4 четверти; три быстрых
повтора перед длинной нотой; легато с изменением высоты; остановку транспорта в середине
длинной ноты; 70/140 и 90/180 с Sync. Сначала измерять на одной высоте, затем во всём
рабочем регистре: транспонирование не должно менять gate/release как при растяжении one-shot.
